# Fannie Lou Hamer Curriculum Site

Standalone student-facing prototype showing how the existing Bronx curriculum could be organized for exploration.

The prototype preserves the school's current curricular arc and keeps Bronx Learning Commons resources in a separate optional extension layer. The extension now includes the broader Bronx ecosystem: archives, youth organizing, environmental fieldwork, documentary storytelling, food justice, arts education, civic action, family support, and borough-wide coalition work. It is not a replacement curriculum and is not yet a full resource archive.
